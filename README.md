# IssueFlow Community

Questions, ideas and announcements for [IssueFlow](https://www.issueflow.cloud): workflow orchestration for AI coding agents.

**→ [Open the Discussions](https://github.com/xirius-ai/issueflow-community/discussions)**

| Category | Use it for |
|---|---|
| 📣 Announcements | Release notes and service notices from the IssueFlow team |
| 🙏 Q&A | "How do I…?" and "Why did my issue…?" questions. Mark the reply that solved it as the answer |
| 💡 Ideas | Feature requests and workflow ideas |
| 🙌 Show and tell | Workflows, stages and setups you want to share |
| 💬 General | Everything else |

Search before you post: someone may have asked already.

## Other ways to get help

- **Documentation:** <https://portal.issueflow.cloud/docs>, public, with no sign-in.
- **Your chat agent:** connect `https://api.issueflow.cloud/mcp` to Claude, ChatGPT, VS Code or any MCP client and ask it.
- **Private problems:** use *Report a problem* in the portal, or email info@xirius.com. Anything involving your account, billing or private repositories belongs there, not here.

## Before you post

- **Never paste passwords, tokens, API keys or private code.** Discussions are public.
- Include what you expected, what happened, and the agent framework you use.
- Be kind. See the [code of conduct](CODE_OF_CONDUCT.md).

Security vulnerabilities: see [SECURITY.md](SECURITY.md). Please don't post them here.
